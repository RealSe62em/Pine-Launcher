THE SHORT VERSION

Questions, answered.

The things worth knowing before Pine touches your Minecraft folder.

Is Pine Launcher free?

Yes. Pine is free and open source, with public code and checksums for official releases.

Which loaders does Pine support?

Vanilla, Fabric, Quilt, Forge, and NeoForge. Every instance keeps its own loader, mods, settings, and worlds.

Does Pine work on Linux?

Yes. Native DEB, RPM, and Pacman packages cover Debian, Ubuntu, Fedora, Nobara, Arch Linux, Manjaro, EndeavourOS, and related distributions.

Do I need to install Java myself?

No. Pine selects and manages the Java runtime required by each Minecraft version.

Can Pine import my existing launcher?

Yes. Pine can import existing instances while preserving worlds, mods, settings, and other gameplay data.

Why does Windows show “Unknown publisher”?

Pine is currently unsigned because trusted Windows signing certificates are paid products. You can verify the published SHA-256 checksum before running it.
