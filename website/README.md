# Pine Launcher website

This dependency-free static website can be previewed by serving the project root and opening /website/.

The download URLs are at the top of script.js. They point to ../dist-native/ for local testing. Before public deployment, upload the installers to a GitHub Release and replace those values with the public release asset URLs. Most static hosts impose file-size limits below the 159 MB universal installer.
